# AirTrail Earth Style

I use dark mode a lot, and I personally like maps with a bit more color
and detail. So I made a custom style for the new basemap feature. It
shows the Earth like a real satellite photo (NASA Blue Marble), with
clean vector map details (roads, airports, labels) fading in as you zoom.

## Features

- Real Earth colors: green forests, tan deserts, blue oceans, white ice
- Smooth fade from satellite photo to vector map when zooming in
- Bright, easy-to-read colors at every zoom level
- One single style file works for both light and dark mode
- Runways, taxiways, and aprons are visible at airports

## How to use it

1. Open AirTrail's map style settings.
2. Paste this file's raw URL into **both** the light and dark map style fields.
3. Save, then click "Test saved map styles".

## Data sources

- Imagery: [NASA GIBS](https://earthdata.nasa.gov/gibs) (Blue Marble)
- Map data: [OpenFreeMap](https://openfreemap.org) (OpenStreetMap data)
